# Fintech Ecosystem

Backend ecosystem untuk layanan keuangan (Auth, User, Account, Transaction, dsb).

## Modules
- `gateway` - API Gateway
- `service-auth` - Authentication & user management
- `service-user` - User profile & account

## Tech Stack
- Java 21 + Spring Boot 3
- PostgreSQL + Flyway
- Docker + GitHub Actions
- JWT Authentication

## How to Run
```bash
./mvnw spring-boot:run
